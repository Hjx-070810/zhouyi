# 梅花易数

先读 [规则与出处](references/rules.md)，根据输入选方法。按需读对应卦的古文，不加载全部六十四卦。

## 排盘

- 已有卦象：核对上下卦、单个动爻与爻位方向，不重新起卦。爻位自下而上。截图不清或缺输入时先澄清。
- 三个数：采用本仓库网站的三数约定，不冒称古籍唯一方法，不混入别的两数法或加时法。
- 时间：需要核实的年支数、农历月日与时支数。公历转换须有可靠历法工具并记录来源、原时间、时区和换日口径。使用当前时间时读取准确时间，默认采用客户端时区并说明。闰月或子时换日影响结果而约定未明时先澄清，不猜日期。
- 无动爻或多动爻：本排盘器不支持。可以讨论卦义，不强行指定体用。

Python 3.10+，仅标准库。以下路径相对于本技能目录：

```text
python scripts/cast.py numbers 1 7 9
python scripts/cast.py manual 2 3 1
python scripts/cast.py lunar 5 12 17 9
python scripts/cast.py --mutual-rule website manual 1 1 3
```

manual 参数为上卦编号、下卦编号、动爻；lunar 为年支数、农历月、日、时支数。
默认 book 规则在乾坤纯卦时取变卦之互；复现网站截图用 website，注明差异。来源不明且两法不同，列明差异或询问口径。
不能执行脚本时可以手算，展示算式与核对过程，不声称执行过。发现用户排盘错误应指出，不受网站提示词中禁止修正的要求束缚。

## 解读

1. 列出输入、方法、本互变卦、动爻、体用和取互口径，分开计算事实与解释。
2. 按卦序读取 [周易古文摘录](references/zhouyi-classics.json) 的对应条目，引用本卦卦辞和实际动爻原文。“乾上乾下”是组成说明，不是卦辞。古文按仓库转录，疑难字句沿 source 核查，不能冒称校勘定本。
3. 讨论体用，再比较两互卦及变用对原体的关系；互变分析保持本卦之体，不重新随意分配。
4. 时间充分才讨论旺衰，注明季节、节气月令或网站农历月简化口径。信息不足不虚构旺衰。
5. 结合八卦象义、动爻与所问之事，说明依据相合或矛盾处。参照 [案例](references/examples.md) 核对，不照搬古例中的人物、事件或应期。外应只用用户实际提供的观察。
6. 给传统框架内的倾向、可观察条件与现实建议，不保证未来事件；应期依据不足时不编造精确日期。

通常按排盘核对、卦理解释、现实建议组织，长度与语气按用户要求。区分古籍规则、项目约定和解释推断。医疗、法律、投资和安全问题，不从卦象给诊断、收益保证或人身灾祸判断。
仓库 docs/ 混有现代作者解释，不能全部当梅花易数原文或整批复制为自创内容。技能已带古文摘录与排盘器，独立于网站运行。
